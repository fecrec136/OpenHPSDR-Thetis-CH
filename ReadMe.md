# Thetis for Linux

A native Linux version of Thetis, the OpenHPSDR console, built on .NET 8 and
Avalonia with the WDSP and ChannelMaster libraries compiled for Linux.
Tested on Linux Mint 21 and 22 with a Hermes-Lite 2 (Protocol 1).

Build, run and feature documentation: [Project Files/Source/Linux/README.md](Project%20Files/Source/Linux/README.md)

The Windows application's sources have been removed; see upstream Thetis
(https://github.com/ramdor/Thetis) for the Windows console.
